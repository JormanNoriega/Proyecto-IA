## Reglas de mantenimiento

1. Diferenciar siempre una propuesta de una función implementada y probada.
2. Registrar aquí los cambios de alcance y sus consecuencias.
3. Actualizar contratos y criterios de aceptación junto con el código que los implementa.
4. No incorporar credenciales, contraseñas ni datasets completos en los documentos.
5. Mantener intactos los informes y resultados históricos de las fases 1 y 2.

## Decisiones pendientes

- Fecha de entrega y capacidad disponible del equipo.
- Fuente, edición, licencia y descarga exacta de las geometrías oficiales.
- Condiciones vigentes y disponibilidad del servicio de mapa base.
- Versiones de dependencias verificadas en el entorno de implementación.
- Nombres definitivos del producto y sus elementos visuales.

Ninguno de estos puntos autoriza a ampliar el alcance automáticamente.
